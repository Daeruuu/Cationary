Cationary - ein englisches Wörterbuch aber mit Hilfe von Katzen veranschaulicht

Auf der Hompage kann man ein englisches Wort eingeben und daraufhin werden automatisch die Daten zu dem Wort von einer öffentliche API abgerufen und auf der details-page angezeigt. Zu dem Wort wird jeweils noch ein Bild von einer Katze geladen. Das Bild der Katze ist randomisiert und wird von meiner kleinen Datenbank von rund 50 Bildern ausgewählt. Der Dictionary bietet Definitionen, Synonyme, Antonyme, die Phonetische Aussprache und ein Audio-File kann abgespielt werden.
Die Website soll einen konstrast zu allen anderen unüberischtlichen und langweiligen Wörterbüchern herstellen und einem die Suche durch Katzenbilder versüssen.

Es ist auch ein Easter-Egg versteckt, also keep your eyes open!
